# NAI Prompt Studio v0.6.7

## Faster, steadier creative work

- Card-heavy workflows feel more responsive during longer sessions, with fewer unnecessary redraws as you move through the studio.
- Artist, character, and Custom Tags previews are retained more reliably while you browse, filter, search, and return to a workspace.
- Artist replacement stays focused and easier to control, with a practical selection range of 2–15 cards.

## Better visual references

- Image Metadata keeps the best available source quality for supported booru references, so saved Custom Tags can retain their original visual detail.
- Preview handling is smoother and more consistent across the studio, including large catalogs and saved collections.

## A more polished studio

- Workspace changes, catalog browsing, and everyday controls feel more stable and deliberate.
- Local libraries have stronger consistency safeguards as collections and shared Custom Tag packs grow.
