# NAI Prompt Studio v0.6.6

## Shareable Custom Tags

- Export any user preset folder as a single `.naipack` file and import it by button or drag and drop. Packs keep tags, descriptions, categories, and original PNG/JPEG/WebP previews together.
- Custom Tags now use a durable file-backed library, with clearer folder controls, safer deletion choices, and polished folder interactions.

## Expanded Image Metadata

- Load supported Danbooru, Konachan, and Safebooru post links to inspect their image and tags alongside the existing local NovelAI PNG/WebP workflow.
- Select prompt text and save it directly into a Custom Tags folder and category with the loaded image as its preview.
- Metadata previews, saved-state reconciliation, selection tools, and workspace re-entry are now faster and more stable.

## Character workflow

- Every Prompt Builder character has its own visual Character Tags constructor and can be saved directly to the library.
- Saved Library adds independent Character records, character filtering, previews, editing, and positive/negative prompt copying.

## Performance and interface polish

- Reduced startup and catalog-validation work, removed delayed character-card redraws, and fixed sticky previews and inconsistent workspace headers.
- Improved animated dialogs, custom selectors, folder controls, and hover behavior across the updated workflows.

The Windows installer is unsigned, so Microsoft SmartScreen may show an unknown-publisher warning.
